# Semana 1 · Agente corriendo de principio a fin

**Objetivo de la semana:** una primera versión del agente que recibe una pregunta, llama a Grok, usa una
herramienta y entrega una respuesta, con el código en un repositorio público y un README.

**Qué se entregó**
- Loop del agente (pensar → actuar → observar) en `agente/agente.py`, con un máximo de vueltas.
- Una herramienta, `consultar_precios`, sobre un CSV de precios de ejemplo (ficticios).
- Conexión con Grok usando el SDK de OpenAI y la configuración en `.env`.
- Log de cada ejecución en `logs/` y pruebas con un LLM falso que no gastan API.

**Retroalimentación recibida:** cumple como S1 básica (bucle mínimo con una herramienta sobre un CSV de
ejemplo); sin datos reales ni video, que no se pedían en esta etapa.

## Agente corriendo end-to-end

```
Pregunta → 🧠 Grok → 🔧 consultar_precios → 👀 resultado → 🧠 Grok → ✅ respuesta + 📝 log
```

**Ejemplo real de ejecución (S1, con los precios de ejemplo de entonces):**

```text
> python main.py "¿Cómo está la urea en Santander?"
  🔧 vuelta 1: consultar_precios({"insumo":"urea","region":"Santander"})

🤖 Urea en Santander (datos de ejemplo): el bulto de 50 kg ha bajado estas semanas.
- 14 sep 2026: $182.000
- 21 sep 2026: $179.500
- 28 sep 2026: $176.000
- 5 oct 2026: $171.000 (último dato)

> python main.py "¿Cuánto vale el glifosato en Nariño?"
  🔧 vuelta 1: consultar_precios({"insumo":"glifosato","region":"Nariño"})

🤖 No hay datos de precios para el glifosato en Nariño.
```

Con el segundo ejemplo se comprueba que el agente **no inventa precios** cuando no tiene datos.

> ⚠️ Los precios de S1 y S2 eran **ficticios**. Desde S3 el agente usa datos reales del DANE;
> `data/precios_ejemplo.csv` sigue siendo ficticio y **solo lo usan las pruebas**.
